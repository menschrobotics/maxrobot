# MAX Robotics Platform

Welcome to the central repository for **MAX**, an open-source robotics ecosystem developed by **Mensch Robotics Private Limited**.



MAX is designed around a modular architecture that brings together physical hardware, computing, wireless communication, and motor control. The ecosystem is organised into dedicated repositories, enabling builders, students, researchers, and developers to explore individual subsystems, understand the platform, customise its functionality, and contribute to robotics development.

---

## 📌 Platform Overview

MAX is a modular educational and development robotics platform designed for hands-on learning, experimentation, and robotics application development.



The platform brings together:

- Robotics hardware and electronics
- Raspberry Pi-based computing
- Bluetooth connectivity and communication
- Motor operation and movement control
- Display and voice interaction
- Robotics programming and AI-based applications

## 🤖 Platform Configurations

MAX supports multiple configurations and modules to suit different robotics applications and development requirements.

| **Configuration** | **Description**              |
| ----------------- | ---------------------------- |
| **MAX Full Body** | Complete robot configuration |
| **MAX Arm**       | Robotic arm configuration    |
| **MAX Base**      | Robot base configuration     |
| **MAX Display**   | Display interface module     |
| **MAX Voice**     | Voice interaction module     |

These configurations offer different ways to explore, customise, and develop applications using the MAX platform.

## 🏗️ Ecosystem Architecture

The MAX ecosystem is organised into one central repository and four supporting repositories, each dedicated to a specific area of the platform.
```
MAX ROBOT ECOSYSTEM
│
├── maxrobot
│   └── Central project repository
│
├── maxrobot_setup
│   └── Raspberry Pi installation and configuration
│
├── maxrobot_hardware
│   └── Hardware architecture and component details
│
├── maxrobot_bluetooth
│   └── Bluetooth communication and connectivity
│
└── maxrobot_motor_control
    └── Motor operation, movement, and control

```
